# ITパスポート QUEST

スマートフォン向けのITパスポート学習アプリ。30問のオリジナル問題、分野別演習、10問チャレンジ、復習、XP、学習記録を提供します。

## 公開方法（GitHub Pages）

1. GitHubで新しい公開リポジトリ `it-passport-quest` を作成します。
2. このフォルダの `index.html` をリポジトリのルートにアップロードします。
3. Settings → Pages → Build and deployment の Source を `Deploy from a branch` にし、`main` / `(root)` を選択します。
4. 表示された公開URLをスマートフォンで開き、ホーム画面に追加できます。

サーバやAPIキーは不要です。進捗は端末のブラウザのlocalStorageに保存され、別端末とは同期されません。ブラウザのデータ消去で記録が消える場合があります。

問題文は独自作成です。IPAシラバス Ver.6.5と公開問題を参考にしています。2027年度の新制度案は正式版ではありません。

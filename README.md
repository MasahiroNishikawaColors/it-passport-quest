# ITパスポート QUEST

スマートフォン向け学習アプリ。IPAが公開した令和5〜7年度のITパスポート試験問題240問と、関連用語を復習するオリジナル60問を収録しています。10問チャレンジでは過去問8問、オリジナル2問を出題します。PC向けには100問の模擬試験を3回分用意し、各回は過去問80問とオリジナル20問です。過去問は模試間で重複せず、オリジナルは2問だけ重複します。

## 問題と出典

公開過去問の問題文・選択肢はIPA公開問題に基づき、正答はIPA解答例と照合しました。出典の年度・問番号と原本へのリンクは各問題の解答画面に表示します。画面表示に合わせて改行・空白を調整しています。外部の図の画像が必要な問題は収録していません。文章中の表データは文字として掲載しています。

- [令和7年度公開問題](https://www3.jitec.ipa.go.jp/JitesCbt/html/openinfo/pdf/questions/2025r07_ip_qs.pdf)
- [令和6年度公開問題](https://www3.jitec.ipa.go.jp/JitesCbt/html/openinfo/pdf/questions/2024r06_ip_qs.pdf)
- [令和5年度公開問題](https://www3.jitec.ipa.go.jp/JitesCbt/html/openinfo/pdf/questions/2023r05_ip_qs.pdf)
- [IPAの過去問題利用上の留意点](https://www.ipa.go.jp/shiken/faq.html)

問題の解説とオリジナル問題は本アプリ用に作成しました。第三者サイトの解説文は収録していません。2027年度の制度変更案は確定したシラバスではありません。

## 利用と記録

`index.html` を開くだけで動作します。GitHub Pagesでは `main` ブランチのルートを公開します。記録は使用端末のブラウザに保存され、端末間では同期されません。ブラウザのデータ消去で記録が消える場合があります。

## 選定の考え方

令和5〜7年度のIPA公開問題300問を小分類別に集計しました。3年合計ではセキュリティ56問、経営戦略マネジメント21問、サービスマネジメント19問、ネットワーク18問、法務・企業活動各17問です。これは公開問題内の出題数であり、今後の本試験での頻度を予測する数値ではありません。頻出の小分類、直近の問題、AI・データ活用などシラバスVer.6.5の内容を重視し、年度別に令和5年70問・令和6年80問・令和7年90問を収録しました。各100問模試はストラテジ35、マネジメント20、テクノロジ45問で構成します。

合格基準はIPAの総合評価点600点以上・各分野別評価点300点以上です。アプリの正答率はIPAの評価点に換算できません。模試の分野別正答数と間違い復習を理解度の目安にしてください。過去のブラウザ学習履歴は問題IDの変更に伴いリセットされます。XPと連続学習日数は引き継ぎます。
